# BDPU-Threshold

Chatzimichail T, Chatzimichail RA, Hatjimihail AT. BDPU-Threshold: Estimating Conditional Disease Probability, Decomposing Uncertainty, and Simulating Test Results. Ver. 1.0.0. Hellenic Complex Systems Laboratory; 2026. https://doi.org/10.5281/zenodo.24443936

BDPU-Threshold estimates the conditional probability that an analytical-error-free reference concentration meets a specified threshold, using paired quantitative test and reference measurements. Its Wolfram Language notebooks provide posterior probability estimates, credible intervals, and parameter, analytical measurement, and total standard uncertainties. The software includes optional age conditioning and a separate parametric-bootstrap simulation workflow.
